# 05: Post 路径

**What to build:** 复用 04 建立的内容层，加入 Post 类型：3 篇占位 Post（覆盖不同日期、标签和摘要长度）和 1 篇草稿夹具。`/writing/` 按日期倒序显示标题、摘要、日期、中文阅读时长、标签和示例标记；`/writing/[slug]/` 显示发布日期、阅读时长、纯文字标签（不生成链接）、由二级/三级标题生成的目录、MDX 正文、上一篇/下一篇和占位提示条；首页 Latest Posts 最多显示 5 篇，不足时显示实际数量。阅读时长按 CJK 字符约 400 字/分钟、拉丁词约 200 词/分钟计算，向上取整，最少 1 分钟。

**Blocked by:** 04（Project 路径，提供通用内容层）

**Status:** ready-for-agent

- [ ] 3 篇占位 Post 按日期倒序出现在列表和首页。
- [ ] 详情页显示日期、中文阅读时长、纯文字标签、目录、上一篇/下一篇和占位提示条。
- [ ] 目录由二级/三级标题生成，锚点可跳转。
- [ ] 草稿夹具不出现在列表或首页，其详情 URL 返回 404。
- [ ] 首页最多显示 5 篇；只有 3 篇时显示 3 篇，不出现空位。
- [ ] E2E 覆盖列表排序、详情要素、首页数量和草稿排除。
